# SculkLauncher
A repository for the Sculk Minecraft Launcher

# IMPORTANT: requirements
you must have a x86_64 stable linux system and two python libs to run this.
```
pip install minecraft-launcher-lib PyQt6 --break-system-packages
```

## What is Sculk Launcher?

Sculk is a local/offline minecraft launcher for linux. its built to be simple and have everything you need without uneeded slop.
Sculk is build in python using minecraft-launcher-lib library. and also using PyQt6 to implement the GUI. The project is still under construction butupdates will be posted in the official SondaProject youtube account.
