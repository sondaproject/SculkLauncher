    Built around what you actually do

    The launcher stays out of the way. Everything below works from one window, and nothing is copied until you drop it in.

    Drop anywhere

    A .jar goes to mods. A .zip is opened and checked: a shaders folder means shader pack, a pack.mcmeta or assets folder means resource pack. Switch mods off without deleting them.

    Finds the instances you already have

    Maps Prism, MultiMC, PolyMC, CurseForge, Modrinth App and the official .minecraft folder in place. Point it at any other folder and it will take that too.

    Any version, any loader

    Install releases, snapshots or old betas, with Fabric, Quilt, Forge or NeoForge, straight from Mojang. The version list is cached, so the Download tab still opens offline.

    Modpacks

    Drop a .mrpack file and it installs as a new instance, loader and all.

    The free demo build

    Turn on Demo mode per instance to run Mojang's own free trial build. No account needed.

    It listens

    Every drop, launch and install sends a pixel ripple across the background, like a sculk sensor picking up a step. It costs nothing while idle.

    Questions

    Short answers, including the awkward ones.

    Windows says "Windows protected your PC". Is it safe?

    The .exe is not code-signed, because signing certificates cost money and this is a hobby project, so SmartScreen warns about any unknown file. Compare the SHA-256 above with the file you downloaded (in PowerShell: Get-FileHash .\SculkLauncher.exe). Or skip the .exe entirely and run the Python source, which is a single file you can read.

    How do accounts work? Can I join any server?

    Sculk signs in offline, using the player name you type. That is enough for singleplayer, LAN and servers that run in offline mode. Servers that check Mojang accounts will refuse it, and the launcher does nothing to get around that. If you enjoy the game, buy it and support Mojang.

    What is Demo mode?

    It starts Minecraft with Mojang's own demo flag, the official free trial. It needs no account at all.

    Does it need Java installed?

    Usually not. When Sculk installs a version it also downloads the Java runtime Mojang ships for it. You can point it at your own Java in Settings.

    Will it mess with my Prism or CurseForge instances?

    No. Existing instances are mapped in place and nothing is copied or rewritten. Files only change when you launch one or drop something into it. Removing a mapped instance from the list only hides it.

    Where does it keep its own files?

    Windows: %LOCALAPPDATA%\SculkLauncher, settings in %APPDATA%\SculkLauncher. Linux: ~/.local/share/sculk-launcher and ~/.config/sculk-launcher.

    Is this made by Mojang?

    No. Sculk is an unofficial fan project and is not affiliated with Mojang or Microsoft. Minecraft is a trademark of Mojang Synergies AB.
